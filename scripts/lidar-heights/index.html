LiDAR building heights

Builds the dataset that scripts/build-building-tiles.mjs turns into the game's building tiles: every OpenStreetMap building footprint in the box below, with the roof height measured from the USGS 3DEP point cloud (Kalamazoo 2015 flight, served as Entwine Point Tiles from the public usgs-lidar-public bucket). Both sources allow this use: OSM under the ODbL (the game credits it), the LiDAR as US public domain data.

Everything runs in this page: Overpass and the S3 bucket both send CORS headers, and laz-perf decodes the LAZ chunks in WebAssembly. Expect roughly 1.7 GB of point data for the default box; it takes a few minutes on a fast connection and then downloads kalamazoo-buildings.json.gz.
